# Atto Equipment Portal — GitHub Pages Test

This is a static test version of the Atto Equipment Portal.

It can test:
- Equipment ID entry
- Demo equipment lookup
- Equipment information editing for a request
- Toner / Service / Clicks tabs
- Browser barcode scanning where supported
- Local test request storage in the browser

Important: GitHub Pages does not provide the production database/backend. Test requests are stored only in the browser's localStorage. This package is for workflow testing, not production use.
